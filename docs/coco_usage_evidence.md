## 5. Guardrails Demonstrated

| Guardrail | Implementation |
|-----------|---------------|
| No LLM arithmetic | All metrics from SQL skills; agent instructed "NEVER compute numbers yourself" |
| Refusal on insufficient evidence | Agent flags "CONFIDENCE: LOW" when data is ambiguous |
| Domain boundaries | Agent refuses questions outside AML/Liquidity/Credit |
| Citation requirement | Agent must call policy_search before citing; no fabricated clauses |
| Separation of fact vs analysis | Agent labels SQL-backed facts vs. generated narrative |
| PII governance | Masking policies: analyst sees masked, MLRO sees full |
| Audit trail | Append-only log with question, SQL, model, user, role, timestamp |
